# 🌐 LifeOS Cloud — Автономная система личного ритма для друзей

Полностью автономная, мультипользовательская версия LifeOS, работающая 24/7 в облаке независимо от вашего компьютера.

---

## 💎 Главные особенности

1. **Полная автономность (24/7)**:
   - Работает на бесплатном хостинге (Render / Railway / VPS) круглосуточно.
   - Ваш домашний компьютер **не требуется** держать включенным.

2. **Защищенный Spatial Auth Gate**:
   - При первом входе незалогиненный пользователь видит стильный экран «Вход / Регистрация».
   - Доступ к разделам дашборда закрыт до момента входа.
   - У каждого пользователя — своя изолированная база данных в SQLite (`lifeos_cloud.db`), зашифрованные пароли PBKDF2 и нулевая утечка личных данных.

3. **Интерактивный 9-шаговый тур**:
   - Сразу после регистрации новый пользователь автоматически проходит обучающий гид по разделам:
     1. Навигация
     2. Пульс дня & соматика
     3. Инкубатор идей (Канбан)
     4. Радар проектов & декомпозиция
     5. Тренировки & RPG-квесты
     6. Медитация & 4 техники дыхания
     7. Утренние страницы (фрирайтинг)
     8. Вечерний разбор дня
     9. Персонализация & безопасность

4. **Искусственный интеллект Gemini (BYOK + Сервер)**:
   - Поддерживает декомпозицию идей и анализ вечера через Google Gemini.
   - Пользователь может вставить свой бесплатный ключ из [Google AI Studio](https://aistudio.google.com/app/apikey) в настройках профиля, либо сервер использует общий ключ.

5. **Zero Dependencies (Чистый Python 3)**:
   - Сервер написан на стандартной библиотеке Python (`http.server`, `sqlite3`, `urllib`).
   - Время сборки и деплоя в облаке — менее 20 секунд. Никаких конфликтов пакетов `pip`.

## 🚀 Как запустить в облаке за 3 минуты (Render.com — Бесплатно)

### Шаг 1: Загрузить папку на GitHub
1. Перейдите на [github.com/new](https://github.com/new) и создайте репозиторий (например, `lifeos-cloud`, можно сделать Private).
2. В терминале в папке `C:\Workspace\1_Work\Projects\LifeOS_Cloud`:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of LifeOS Cloud"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/lifeos-cloud.git
   git push -u origin main
   ```

### Шаг 2: Создать Web Service на Render.com
1. Зарегистрируйтесь или войдите на [render.com](https://render.com) (бесплатный тариф Free Web Service).
2. Нажмите кнопку **«New +»** ➔ **«Web Service»**.
3. Выберите ваш репозиторий `lifeos-cloud` из списка GitHub.
4. Заполните настройки:
   - **Name**: `lifeos-app` (или любое желаемое имя)
   - **Region**: Frankfurt (EU) или любой ближайший
   - **Language**: `Python 3`
   - **Branch**: `main`
   - **Build Command**: `pip install -r requirements.txt` (пройдет моментально)
   - **Start Command**: `python server.py`
   - **Instance Type**: `Free`
5. *(Опционально)* В разделе **Environment Variables** добавьте:
   - `GEMINI_API_KEY`: ваш ключ Gemini (если хотите предоставить друзьям ИИ без ввода их собственных ключей).
6. Нажмите **«Deploy Web Service»**.

Через 30–60 секунд Render выдаст вам постоянную ссылку:
👉 `https://lifeos-app.onrender.com`

Эту ссылку можно смело давать друзьям. Они смогут зарегистрироваться, пройти интерактивный тур и пользоваться своим личным пространством в любое время суток с iPhone, Android, планшета или ноутбука!
